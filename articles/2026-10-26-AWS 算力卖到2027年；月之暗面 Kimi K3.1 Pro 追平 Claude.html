AI 前沿速览

算力卖断货，模型又追平

2026 年 10 月 26 日

AI 的两端同时传来信号：需求端，亚马逊 AWS 的大批量算力已经卖到了 2027 年，砸下约 2200 亿美元还是不够用；供给端，月之暗面 Kimi K3.1 Pro 上线，编程能力追到了只差 Claude 旗舰 0.7 个百分点的位置。下面拆开讲透。

大事件 01

AWS 算力卖到 2027 年：贾西称 2200 亿美元开支仍不够

据路透社报道，亚马逊首席执行官安迪·贾西在风险投资机构 a16z 的播客访谈中透露：受 AI 算力需求暴涨拉动，亚马逊云科技 AWS 的大批量云计算资源已经基本卖到 2027 年，还有相当一部分长期客户订单直接锁定至 2028 年。换句话说，2026 年的批量算力容量已经售罄，2027 年也基本订满。

这并不是说 AWS 一点余量都没有。按贾西的说法，亚马逊会保留一小部分算力，留给按需业务、EC2 云服务器以及 Bedrock AI 推理服务；真正被抢光的，是适合大客户大批量采购的那部分。AI 科研机构和各行各业的企业客户对训练、推理算力的需求仍在持续爆发，亚马逊只能全力扩建基础设施去追。

更值得注意的是数字本身：即便亚马逊计划在 2026 年投入约 2200 亿美元资本开支，用于数据中心、服务器等硬件建设，依旧难以完全消化市场需求。贾西的判断是：从需求看，继续加码基建并非低效的资金消耗，企业还可以进一步投入。算力短缺从一句口号，变成了云厂商财报和订单簿上的现实。

📊 要点速览

· AWS 大批量算力 2026 年售罄、2027 年基本订满，部分订单锁定至 2028 年

· 保留小部分算力给按需业务、EC2 与 Bedrock 推理服务

· 2026 年资本开支计划约 $2200 亿，仍难完全满足需求

· 贾西判断：继续加码基建不是浪费，需求还在爆发

消息来源：路透社、环球网（2026-10-25）

大事件 02

月之暗面 Kimi K3.1 Pro 上线：编程能力只差 Claude 旗舰 0.7 分

10 月 24 日，月之暗面正式发布 Kimi K3.1 系列的首个模型 Kimi K3.1 Pro。它不是一个全新的基座模型，而是基于今年 7 月发布的 Kimi K3 做的大规模后训练升级：强化学习扩展至数百个下游领域，并系统性优化了训练框架与长上下文推理效率，目标直指代码、3D 创作、金融研究和长程 Agent 任务。

规模上，它仍是 3 万亿级参数、支持 100 万 Token 超长上下文。最亮眼的成绩在考察真实终端编程能力的 Terminal-Bench 4.0 上：K3.1 Pro 得分 65.7%，超过 GPT-6 Astra 的 58.2%，与 Claude Opus 5.5 的 66.4% 仅差 0.7 个百分点。在第三方机构 Artificial Analysis 的智力指数榜单中，它以 55 分位列全球第四，仅次于 Claude Opus 5.5、Claude Sonnet 5.5 和 Muse Wonder Full。

同步推出的还有高速版 Kimi K3.1 Pro Highspeed，能力与标准版一致，输出速度提升约 2 至 3 倍。两款模型已在 Kimi 网页端、App、Kimi Work、Kimi Code 及 API 上线；API 定价为每百万 Token 输入 2 美元、输出 10 美元，较前代整体下调约 33%。完整模型权重计划于 11 月 4 日前开源发布——到时独立测评才能验证这些厂商成绩，结论先打个“待验证”的标记。

🚨 要点速览

· K3.1 Pro 是 K3 的大规模后训练升级，3 万亿级参数、100 万 Token 上下文

· Terminal-Bench 4.0 得分 65.7%，超 GPT-6 Astra（58.2%），距 Claude Opus 5.5（66.4%）仅 0.7 分

· Artificial Analysis 智力指数 55 分，全球第四；高速版快约 2–3 倍

· API 降价约 33%（$2 / $10 每百万 Token）；权重计划 11 月 4 日前开源

消息来源：月之暗面、新浪科技、三言科技（2026-10-24）；基准成绩为厂商公布，待独立验证
